### Bayatni.tn

Bayatni.tn is a hotel booking and reservation platform that allows users to search, compare, and reserve hotels across Tunisia.
This project demonstrates a complete web application with booking workflows and administrative management.

### Key Features
- Hotel search by location and availability
- Hotel reservation and booking system
- Price display and comparison
- User accounts and authentication
- Admin management for hotels and bookings

### Technologies Used
- PHP
- HTML
- CSS
- JavaScript
- MySQL (or compatible database)

### Project Structure
admin/            Admin dashboard and management
app/              Core application logic
includes/         Shared components and helpers
model/            Application models
public/           Public assets (CSS, JS, images)
.htaccess         Server configuration
README.md         Project documentation

###Getting Started

1. Clone the repository
```bash
git clone https://github.com/fdehech/Bayatni.tn.git
cd Bayatni.tn
```

2. Requirements
- Web server (Apache or Nginx)
- PHP
- MySQL
- Browser

3. Configuration
- Create a database
- Import the SQL schema if provided
- Update database credentials in the configuration files

4. Run the project
Place the project folder inside your web server directory and access it via:
http://localhost/Bayatni.tn

Usage
Users can:
- Browse available hotels
- View hotel details
- Make reservations

Admins can:
- Manage hotels
- Manage bookings
- Monitor platform activity

Limitations
- No online payment integration
- Basic UI
- No mobile optimization (if applicable)
